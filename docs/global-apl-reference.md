## Evidence policy

1. Prefer current Global client/database/patch evidence.
2. Use Global guides as corroboration for ordering, not proof of hidden state.
3. KR/TW evidence is corroboration only when Global evidence is incomplete.
4. Never infer a proc, charge completion, stack count, specialization, target debuff, or cooldown modifier from generic activity.
5. Every executable conditional priority needs present/absent regression coverage.

## Coverage meaning

Optimization coverage estimates evidence-backed decision coverage, not percent of theoretical maximum DPS. A class approaches 90% only when major priorities, conditional chains, readiness, important state, build gates, and regressions are represented.
