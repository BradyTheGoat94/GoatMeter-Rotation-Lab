# GoatMeter Rotation Lab

**Experimental repository.** This is an isolated copy of GoatMeter for developing a passive rotation assistant.

- Production repository: `BradyTheGoat94/GoatMeter`
- This lab does **not** publish GoatMeter releases.
- No automatic key presses, input simulation, game injection, memory modification, or anti-cheat bypassing are part of this project.
- The goal is passive combat-state analysis and next-skill recommendations that the player executes manually.

## Test the beta

Download `GoatMeter-Rotation-Lab-win-x64` from a successful **Build Rotation Lab** run in this repository's Actions tab. Extract the whole ZIP into a separate lab folder and run `GoatMeter.exe`.

The package includes BETA-TESTING.md, BETA-STATUS.md, and BUILD-INFO.txt. Lab data lives under `%LOCALAPPDATA%\\GoatMeterRotationLab`. All eight class profiles remain provisional and informational.

See [beta test guide](docs/beta-testing.md) and [class status and percentage definitions](docs/beta-status.md). Optimized-DPS percentages remain unmeasured; prior coverage estimates are explicitly labeled.

## Meter features

Live damage, class colors, encounter history, detailed reports, and overlay styles are inherited from the GoatMeter baseline. See [accuracy and reliability](docs/accuracy-reliability.md) for remaining protocol and live-validation limits.
